# 公共控制语义：修改前规范

参照main `f68115e`。协议和原失败捕获在`artifacts/public-control-semantics-20261112/`封存；Agent及契约保持原样。以下是本轮拟实现范围，最终是否通过须以逐项结果为准，不将设计写成已完成。

| 状态 | 定义 |
| --- | --- |
| origins | 结果数据取自哪些实际声明读取出现；常量不因控制而获得数据来源。 |
| selectors | 哪些实际声明读取影响值、写入或成员的选择；条件的origins与已有selectors进入受控结果的selectors，保留其原数据来源。内部执行参数坐标不自动注册成新的声明来源。 |
| unknown | 必要来源、选择或效果未确定。实际操作数和分支结果可见，不足以将未知依赖变为known。 |
| 控制范围 | 对已核验原字节码建立正常CFG、唯一出口及立即后支配汇合点。实际条件进入到汇合前的作用域；汇合时合并两侧可能定义的局部槽位／可解析写效果，随后结束活动控制。此前生成的值和写状态继续保留依赖。 |

分支事件必须与当前Frame、指令PC和实际操作数核验，不以事件的taken代替依赖事实。短路未执行的读取不成为来源。循环只累计实际迭代中的条件，退出时处理循环携带状态，包括零次循环；不把所有历史条件永久加入整个Frame。每个调用有独立上下文，调用者控制可约束被调用者的结果和效果，返回／异常后恢复调用者上下文。

| 形态 | 本轮支持计划／限制 |
| --- | --- |
| 比较返回、局部赋值、三元、嵌套及短路 | 支持原内核已有条件指令；要求原字节码CFG和实际分支闭合。 |
| 循环 | 条件支持：有限实际执行、原执行预算、可核验的汇合与携带定义；不声称任意非终止程序支持。 |
| 字段写入和别名 | 条件支持：保留实际身份、声明字段及版本；未执行路径的潜在写入也需可解析接收者／闭合效果，不能凭值相同忽略。无法限定必要效果时不认证。 |
| 调用、集合筛选 | 公共返回值传递控制状态，框架继续核验其自身次序、效果与异常；不为removeIf添加专用来源公式。 |
| catch／finally | 条件支持：沿原有已支持异常分派，使用实际异常及原异常表；异常边界必须有明确的范围转移和清理。 |
| 递归 | 非入口递归受既有深度预算；每次实际Frame独立。原协议不支持的查询入口重入继续拒绝。 |
| switch、jsr/ret、未知字节码或任意反射/native／共享并发 | 不在本轮新增范围；明确拒绝或保持必要unknown，不扩大框架契约。 |

认证保持条件分别比较数据出现、字段版本、完整selectors和known状态。独立预期先于预测建立。原分支谓词反例和直接布尔返回正例均保留；新增正例不能替换原失败。旧业务缺少独立选择真值时，只报告数据／版本保持和选择变化，不推断选择正确。
