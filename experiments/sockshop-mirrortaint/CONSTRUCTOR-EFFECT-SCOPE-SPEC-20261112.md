# 受限构造效果摘要与许可门槛

原操作仍是JVM NEW／invokespecial构造链；构造不会因分配新对象而自动无副作用。摘要须先完整解析，后发布资格；没有完整许可不改变失效范围。本轮不能从旧日志补造JDK内部写入、初始化或native事实。

摘要输入为锁定字节码、实际类及调用候选、形参与实参绑定、已有构造链和当前可达性。分类：

- 写地址：fresh-this的直接字段；参数或this字段可达的旧对象；静态／全局／数组；未解析地址。
- 引用边：保存到新this的参数／外部引用继续登记，不能使外部对象私有；this／参数流向全局或未知调用视为发布义务。
- 调用：父构造、已解释方法、虚分派、native、未知回调分别记录。完整Frames可解释副作用不等于该构造是local-only。
- 生命周期：原分配token、caller／PC、构造ID、实际对象、初始化前后Frame、实际写和版本、正常／异常完成必须一一闭合。初始化、方法覆盖和运行时实现须另核验。

静态候选仅限整个链直接写fresh-this、引用存储可解析、无参数／全局写、未闭合发布／回调／native，且类初始化无未解释效果。必须再以省略／范围收缩之前可用的真实运行事实核验。静态哈希匹配、调用正常返回或字段末态相同均不足以发证。

实际执行时保留每次字段写版本、引用边和原完成；仅在所有必需证据通过后缩小旧状态失效。未执行分支没有实际写入，其可能效果只用于选择合流：local-only许可可排除对旧字段的影响，其他效果按公共call_write_effects解析或继续保守处理。汇合后的新常量／较晚已验证写可建立新状态。

固定JDK Throwable链必须单列native／JDK契约；不得因异常类名、消息或scenario编号授予许可。缺少这项完整证明时，原66项继续按原独立预期评分，不以补充正例抵消6个unknown。
