## 声明支持范围

统一绑定接受显式响应 JSON pointer（列表索引用 `*` 查询族）及声明字段。规划检查整个根方法的受支持指令和控制流；不忽略表面切片以外的未支持指令。无一般循环、invokedynamic、引用数组分配、反射/native 写或并发共享修改保证。

支持已建模普通 DTO、明确的包装 `data`、已知 List 元素和字符串 Map 键。静态选择一个 profile，不再依次运行多个规划器再取成功结果。局部标量计算不要求存在 Map.put。现有复制、归约和集合 profile 继续保留。

根调用返回记录只证明实际返回对象/字段/版本与序列化路径的绑定，**不能成为来源**。来源边界沿用候选协议：入口业务参数、显式 Spring Data 读取返回的实体字段/元素，以及本次实际下游 RPC 响应读取；不恢复数据库历史，也不把边界移到响应目标。

Agent 核验原类哈希，记录字段写入计数版本、实际根调用、源读取调用及真实返回对象。默认 Jackson 的具体属性、getter、serializer、Map 键与运行时类型必须通过核验；动态或自定义配置不按同值猜绑定。接收集合的只读契约由已覆盖修改调用和内容核对保护；不声称覆盖任意外部修改。

显式公共库契约限于已有 JsonUtils 默认 Jackson 转换、直接 getter/setter/纯构造器、支持类型的 List 只读访问、ResponseEntity/HttpEntity.getBody、Resource.getContent，以及旧版已有的 RabbitTemplate 发送不修改消息契约。必要的未建模调用结果或效果仍产生 unknown。库契约及其版本必须披露，不称任意调用的自动证明。

## 运行与独立核验

接受的真实查询使用原版 JAR，通常 6 组输入，Basic 使用现有真实多来源路径的 8 种正常/异常模板，新生成具体值。空列表没有元素目标，单列 N/A；业务实际产生字段但证据缺失时不能列 N/A。每个目标从客户端实际响应枚举，不能只统计采集到的字段。

独立真值由原字节码和输入/数据库事实确定投影位置，再读取原始源调用的对象、字段、版本、调用/消息坐标。真值程序在实验驱动中，不能进入规划器、Agent 或还原器；不使用 TF 依赖图来选择预期来源。未知 helper 若尚无独立来源位置，不宣称其答案已验证，单列 oracle unavailable。

报告分别列规划接纳/拒绝，运行目标实例 known/unknown/证据无效、未产目标请求 N/A，可回答率，以及已知且有独立真值的完全匹配率和关系 TP/FP/FN。完整覆盖结论与条件准确率分开。列表查询族的候选计数与具体字段实例计数分开。

拒绝保护至少包括：未建模必要 helper、缺失返回或来源记录、返回对象错误、歧义返回/消息、同值自定义序列化器，以及旧集合变更/虚调用检查。小程序只补语义证据，不替代原版应用。
