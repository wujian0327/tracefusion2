# ngiflib 码值来源：本地模拟核验

状态：**原始 ELF 指令的本地模拟与来源重放已通过；没有真实 BPF 采集、libdft64 对照、性能结果或漏洞复现。** 不得将本文件的结果与既有 24 个 C 查询的真实主机对照混为一组。

## 查询与实现

目标为每次 `GetGifWord` 返回的低 16 位码值，查询来源限定为该函数内部成功调用 `GetByteStr` 后填充的压缩数据字节。文件偏移由本地读取模型的游标给出，不通过查找相同字节值猜测来源。每个字节的来源身份包含文件偏移与缓冲区写入版本，同一地址再次填充会覆盖旧版本。

`query.py` 从实际 ELF 的符号与指令建立计划，发现 `GetGifWord` 内部的直接调用；使用已配置的 SysV AMD64 ABI 和 C 类型名，编译头文件布局探针，并与 ELF DWARF 类型逐项核对。它不自动发现业务来源边界，也不寻找全局最优探针。

`scripts/c_bit_machine.py` 提供独立于 GIF 格式的有界指令执行，复用已有条件码与分支判断。新增部分寄存器、字节内存、16 位返回值、零扩展、移位、按位组合与掩码语义。来源按位路由，最终投影到输入字节；普通加减仍采用保守来源并集，不宣称支持任意算术的最小位依赖。未知指令、调用、地址、未初始化读、未知返回来源以及不完整证据均拒绝，不把拒绝记作空来源。

`query.py` 保留相邻调用间的残留位和缓冲区来源。调用方提供的码宽、掩码属于声明的固定元数据；像素状态、对象地址、控制条件和字典来源不纳入当前显式数据查询。动态地址和比较操作遇到的来源另列，不能把这个局部记录当作完整控制依赖分析。

当前使用 **boundary replay**：入口/返回快照以及两个读取辅助函数的调用记录足够驱动重放。推断器不读取逐指令轨迹，也不导入参考解码器或真值文件。当前没有实现这一场景的 selected/all 选点对比，不能声称证明选择性内部探针的必要性或优势。

## 与真值的隔离

`check_query_local.py` 使用上一轮已经验证的同一个 `gif2tga-native` ELF，在 Unicorn 中执行原始 `DecodeGifImg` 循环及其调用的原始解码/像素函数；没有替换码值计算函数。它从容器元数据建立模拟的父对象、调色板与帧缓冲，标准库的 `getc`、`fread`、`memcpy`、`malloc` 使用明确的本地摘要。没有在模拟器内运行完整应用的 `main` 或真实 libc。

`gif_reference.py` 依据 GIF89a Appendix F 独立展开位流和 LZW 字典，自行计算码宽、码值及文件字节窗口。它不读取目标程序的码值、码宽状态、探针选择或推断标签。推断完成后才生成来源真值；参考解码像素同时与 Pillow 核对，原始 ELF 模拟的像素也与 Pillow 核对。模拟器记录的实际指令路径只用于事后核验重放路径，不传入推断器。

这里的真值是“固定声明元数据时，码值使用的位所处的输入字节”，**不是普通字节级污点引擎的指令依赖真值**。未来与 libdft64 对比时，应分别报告其传播语义、格式来源覆盖与额外来源，不能把两种定义混用后直接宣称对方错误。

两种模式为真彩色与索引色，共 **510 个不同的输入码值位置、1,020 次模拟查询执行**，不能描述成 1,020 个独立用例。全部码值和来源集合与独立参考一致，TP=2,040、FP=0、FN=0；8 次模拟解码的像素均一致。没有新增图片或重跑上一轮原生转换。单个输入最大两次填充，不声称已验证更广泛的长文件、字典满、11/12 位码宽、多帧或并发场景。

12 项记录故障检查拒绝了错误 ELF/输入身份、不完整采集、未核验后端、缺失/重复调用、缺失填充、错误读取偏移、错误父对象、错误返回、读取内容损坏及跨调用状态变化。另有 4 组 ISA/语义测试：176 组与 Unicorn 的指令数值差分、移位掩码的逐位扰动来源检查、同值覆盖/部分写入，以及未知和越界拒绝。

机器可读结果：`query-local-validation-20261010.json`。

## 复现与下一步

依赖是本地开发模拟依赖，不需要 Pin 或 BPF：

```bash
python3 -m pip install -r experiments/ngiflib-patched/requirements-local.txt
python3 experiments/ngiflib-patched/check_query_local.py \
  --validation /path/to/existing-ngiflib-normal-validation \
  --output artifacts/ngiflib-query-local
python3 -m unittest discover -s tests -p test_c_bit_machine.py -v
```

`--validation` 使用已有 `validate_normal.py` 输出，包含原始 ELF、固定来源文件、4 张正常图片与摘要。脚本核对已有二进制、源码摘要与修订，不重新构建/运行原生正确性实验。输出目录必须不存在；保留计划、边界记录、推断、独立参考和逐查询评分。

下一步仍是同一查询的真实主机边界采集与原版 libdft64 接入：可靠记录文件身份、读取偏移、填充版本、对象/调用实例和完成状态，复核上游传播语义，并统一双方来源边界。主机入口现已实现（见 `HOST-COMPARISON.md`），原始日志需通过独立运输格式核验后才能进入推断。新的 Pin 后端未在当前环境执行成功，等待主机回传；本文件保留的 1,020 次结果仍全部是模拟证据。

格式参考：[GIF89a 规范 Appendix F](https://giflib.sourceforge.net/gifstandard/GIF89a.html)。
